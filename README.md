# 🎬 Netflix Data Analysis (EDA) Project

This project explores the Netflix Titles dataset using Exploratory Data Analysis (EDA) to uncover trends in content type, genres, release year, ratings, and more.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ChunanyaChoudhary/Netflix-EDA-Project/blob/main/Netflix_EDA_Project%20(2).ipynb)

### 📁 Dataset
- `netflix_titles.csv` - Contains 8000+ titles from Netflix (Movies & TV Shows) with details like director, cast, country, rating, etc.

### 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

### 📊 Analysis Performed
1.  Movies vs TV Shows Distribution
2.  Ratings Analysis
3.  Top 10 Countries with Most Content
4.  Content Added Over Years
5.  Most Common Genres
6.  Release Year Trends

### 🚀 How to Run
1. Clone the repo: `git clone https://github.com/ChunanyaChoudhary/Netflix-EDA-Project.git`
2. Open `Netflix_EDA_Project (2).ipynb` in Jupyter / VS Code / Colab
3. Run All Cells

### 📈 Key Insights
- Netflix has more Movies than TV Shows
- US is the top content producer
- Content growth peaked after 2018
